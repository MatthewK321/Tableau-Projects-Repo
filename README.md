# Tableau Retail & Sales Dashboard Project

## Overview
This Tableau project was completed as part of a **Data Technician Bootcamp** and focused on transforming retail and sales data into interactive, insightful dashboards. The project demonstrates the use of Tableau's data visualization and analytics capabilities to explore sales performance, identify trends, and communicate key business insights through effective data storytelling. 【1-7798d9】

## Objectives
- Analyse retail and sales data to uncover business trends.
- Create interactive dashboards to support data-driven decision-making.
- Develop visualizations that clearly communicate insights to stakeholders.
- Apply data storytelling techniques to highlight key performance indicators and trends.

## Skills Demonstrated
- **Interactive Dashboard Design**
  - Built user-friendly dashboards with dynamic navigation and interactivity.
  - Enabled data exploration through filters and dashboard actions.

- **Filters and Slicers**
  - Implemented interactive filters to allow users to drill down into sales data by key dimensions such as region, product category, and time period.
  - Improved dashboard usability and custom analysis capabilities.

- **Calculated Fields**
  - Created custom calculations and metrics to derive additional business insights.
  - Applied calculated fields to compare performance measures and identify trends.

- **Data Visualization**
  - Developed a variety of chart types, including:
    - Bar Charts
    - Line Charts
    - Pie Charts
    - Geographic Maps
  - Selected appropriate visualizations to effectively represent different data relationships and patterns.

- **Data Storytelling**
  - Structured dashboards to present findings in a clear and logical flow.
  - Highlighted key sales trends, performance drivers, and business opportunities.
  - Transformed complex datasets into accessible visual narratives for stakeholders.

## Key Insights Explored
- Sales performance across different regions and locations.
- Product category trends and top-performing products.
- Time-based sales analysis and growth patterns.
- Geographic distribution of sales using map visualizations.
- Comparative analysis of business metrics using calculated measures.

## Tools Used
- **Tableau Public / Tableau Desktop**
- Data Preparation and Transformation Techniques
- Dashboard Design Best Practices
- Interactive Data Visualization Methods

## Outcome
The project demonstrates the ability to analyse retail and sales data, create engaging and interactive Tableau dashboards, and communicate actionable business insights through effective visual storytelling. It showcases practical skills in dashboard development, calculated fields, filtering, and data-driven decision-making gained during the Data Technician Bootcamp.
